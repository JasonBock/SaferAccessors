# SaferAccessors

A C# source generator to make Reflection faster and safer using unsafe accessors in an automated way.

## Getting Started

Reference the `SaferAccessors` [NuGet package](https://www.nuget.org/packages/SaferAccessors). Furthermore, this package only works with .NET 10 and above.

### Prerequisites

The `SaferAccessors` package targets .NET Standard 2.0, though the code it emits is not limited to .NET Standard 2.0.

## Usage

Please read the [Overview document](https://github.com/JasonBock/SaferAccessors/blob/main/docs/Overview.md) for information on how to use this library.
